Al enviar una petición POST a http://localhost:3000/registro con el JSON:
{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor responde con el siguiente objeto JSON:
{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Explicación: Esto ocurre porque el servidor lee los campos del cuerpo de la petición (req.body.nombre y req.body.mensaje) gracias al middleware express.json() y los devuelve en un objeto de respuesta formateado con res.json().
